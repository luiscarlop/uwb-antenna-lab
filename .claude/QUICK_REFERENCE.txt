HOW TO USE AN AGENT (5 Steps):

1. COPY the appropriate template from agent_prompt_templates.md
2. FILL IN your specific context (be detailed!)
3. PASTE the template into chat
4. READ the agent's analysis carefully
5. RECORD the decision in your decision log

═══════════════════════════════════════════════════════════════════════════════

DAILY USAGE PATTERN:

Monday:       Planning phase
              → Algorithm Agent (15 min) - validate this week's approach
              → Architecture Agent (15 min) - any refactoring needed?
              
Tuesday-Thu:  Implementation
              → Debugging Agent (as needed) - fix issues
              → Performance Agent (if slow) - optimize
              → Quality Agent (code review) - before committing
              
Friday:       Review & documentation
              → Thesis Agent (20 min) - document what you learned
              → Decision Log - update all decisions made this week
              
Thesis Phase:  Final 2-3 weeks
              → Thesis Agent - all sections (methodology, results, etc)
              → Quality Agent - reproducibility check

═══════════════════════════════════════════════════════════════════════════════

KEY PRINCIPLES:

✓ BE SPECIFIC with context - agent quality depends on detail
✓ INCLUDE ACTUAL CODE - don't describe, paste it
✓ SHOW YOUR THINKING - explain what you've tried
✓ FOLLOW UP - tell agent if recommendation worked
✓ DOCUMENT DECISIONS - keep decision log for thesis
✓ VALIDATE CLAIMS - don't just accept first recommendation
✓ ITERATE - first answer often needs refinement
✓ CHALLENGE - ask "why" and "when would this fail?"

COMMON MISTAKES TO AVOID:

✗ Vague questions → "Help with my code" (too vague)
✓ Specific questions → "Capon beamforming gives 3° angle error instead of 1°"

✗ No context → Pasting code with no explanation
✓ Full context → Array config, signal type, expected vs. actual behavior

✗ One question then never follow up
✓ Sessions where you validate recommendations worked

✗ Accepting first answer without thinking
✓ Asking "Why?" and "When would this fail?"

✗ Not recording decisions
✓ Decision log entry for every major choice
